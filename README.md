“Proqram təminatı hazırlayıcılarının və proqram təminatı testçilərinin əməkdaşlıq edə biləcəyi bir veb platforma yaradın. Platformaya e-poçt identifikasiyası, istifadəçi profilləri, mesajlaşma, CV yaradılması, CV saxlama, layihə səhifələri, səhv hesabatı, səhv izləmə, ekran görüntüləri, fayl yükləmələri, bildirişlər və müasir cavabdeh dizayn daxil olmalıdır.”

## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
